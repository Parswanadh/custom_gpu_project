## 5. Feasibility vs simulation results

## 5.1 Can FPGA reproduce similar behavior?
**Yes, high functional feasibility** (RTL-first stack, fixed-point pipeline, existing test vectors).

Likely divergence sources:
- Timing closure edits (extra pipeline registers)
- Memory arbitration effects on real DDR path
- AXI/control sequencing under real clocks

## 5.2 Performance realism
For first bring-up, expect:
- Fabric clocks often lower before closure (~80-150MHz typical early phase)
- Effective cycles can increase vs idealized simulation due to memory/control overhead
- Practical first-hardware throughput commonly ~0.5x to 0.9x of optimistic pure-sim headline

So you should communicate **trend confidence high, absolute token/s confidence medium until board measurement**.

## 6. Tech stack + SOTA positioning

### 6.1 Stack in use
- Verilog-2005 accelerator RTL + subsystem modules
- Verilog testbench + cocotb-oriented cosim scaffolding
- Python automation for extraction/benchmark/validation
- Next.js/TypeScript web presentation and measurement UI

### 6.2 Frontier vs lagging
- **Frontier/competitive:** architecture experimentation, quantization-aware pipeline direction, transformer hardware decomposition, reproducible simulation workflow.
- **Lagging for production:** formal synthesis/timing/power closure evidence, board-level validation artifacts, hardened deployment flow.

**Net assessment:** strong architecture R&D stage; not yet hardware-closure-complete.

## 7. Budget decision rules

1. **₹30k-60k** and first silicon proof required -> **Arty Z7-20 class**
2. Need strong India distributor purchase path with known Zynq ecosystem -> **ZedBoard / Zybo Z7-20 class**
3. Need larger headroom for scaling after first success -> **KV260**
4. Need low-cost exploratory modules only -> **Cmod A7 / ECP5 eval**
5. Need Intel-only toolchain -> **Cyclone V SoC board class** (expect weaker India stock visibility)
